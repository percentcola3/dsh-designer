2. Fresh reread and archived snapshot comparison are different actions. Fresh requires `captureSelection:{pageId,stateId,viewportId}`, captures/imports actual new data, freezes the returned source/version/capture and immediately compares that version. Connection-required/error never enables apply or falls back to an old visual result. Existing proposal CAS and selected-node beforeHash remain.
3. Source generation has actual taskId/requestId/sessionId and persisted savedPageIds/pageRevision/contentHash receipts, including page.create and legacy artboard.create. Native status resolves the exact RPC's containing turn/start to matching turn/end. Only completed is normal; blocked/max-tokens incomplete, error failed, aborted cancelled, missing unknown. Workspace/project/source reads decorate status without readonly metadata writes. Binding applications also use native terminal status.
4. Visual and interaction reviews require explicit user action, exact task/request, saved-page subset and concrete evidence note. Current bytes/revision/hash must still match. Reviews are user attestations, not automated raster/interaction verification. Partial coverage remains pending; external drift is stale. Empty-design output has partial/unknown expected coverage, never fabricated complete source coverage.
5. Source outlines are grouped by page/state/viewport with bounded pagination beyond500. Official discovery uses only actual advertised get_metadata and actual supplied IDs/thumbnails; unsupported capability/schema/prose and connection/auth failures remain explicit. UI expands/searches loaded hierarchy and reads continuation pages. It never invents provider frames.
6. Project default binding uses a zero/one selector and null clear; design inherit/independent/none is separate. Fixed version validation rejects invalid explicit values rather than silently choosing latest.
7. Apply-system UI previews the entire design, explicitly chosen pages, or actual Canvas selected objects. It clones the confirmed page/node IDs and pinned binding for submission/retry, ignores superseded owner responses, and preserves actual saved/native status.
8. Offline HTML/ZIP compare returns selected immutable HTML and scoped assetBase only to the user. Oversized HTML is explicitly unavailable rather than silently claiming complete rendering. ZIP entry IDs use sourceEntry/exact canonical URL, survive reordering and encoded names, preserve source plan/selected flags on fresh reread, and refuse missing chosen entries before mutation. Explicit or recorded exported-file provenance uses import instead of website navigation.
9. System version editor hydrates/renders/saves complete tokens/guidelines/examples/skeletons/variables/resources from the selected historical version. Explicit text-resource drafts and same-logicalPath binary replacement create a new version; stale storage/hash/capability metadata is stripped. Save/keep/discard/cancel guards distinguish applying a draft to the form from persisting a new immutable version. Kept drafts are explicitly panel-session memory, cleared on panel unload/reload.
10. Returned import/capture connection-required/error no longer reaches the legacy saved-success message; earlier success is cleared when a new attempt starts.
