# 功能说明

此文保留插件已有功能与边界说明。安装、开发和发布以仓库根 README、CONTRIBUTING 与发布说明为准；历史验收记录不代表当前环境已验证。

## 开始使用

从 DSH 会话标题栏或侧栏进入“设计师模式”。标题栏入口记住当前普通会话的权限上下文。工作台占满工作区并隐藏默认侧栏；“返回默认模式”恢复原布局。

进入后显示首页需求输入和项目卡片；项目管理保留分组、搜索、归档与回收站。进入具体项目后挂载画布和 AI 对话。项目切换保留各自的标签、草稿、相机和目标；关闭查看标签或返回管理页不会取消正在执行的项目任务。

新项目可选择名称、保存父目录、业务目标、平台和默认设计体系。工作台创建独立项目目录、README、需求与规则文档及资源入口，不自动编造业务页面。既有源码通过登记目录关联，默认只读，不强制搬入设计库。旧版 HTML、页面 ID、资源、绑定和历史继续可读；损坏或不可访问的单个条目会明确显示状态，其他项目仍可使用。

项目下可以建立多个设计，每个设计拥有自己的页面和资源目录。新建设计提供需求生成、网站复刻和 MasterGo 还原入口，并保留 Figma 支持。采集来源与生成设计是两个阶段：先确认页面、节点、视口和状态，再确认生成目标。

## 诊断与优化

设置和项目设置中新增「诊断与优化」：检查环境、生成准备、规范资源和知识库元数据，给出证据、建议与渐进指南。支持复制摘要给 DSH AI，也可直接让 AI 调用 `diagnostics.run`、`diagnostics.catalog`、`diagnostics.guide`。用户已要求的改进通过现有项目工具与版本检查执行，再重新诊断；不自动修改插件、账号或权限。检查不触发模型、网络、命令或索引，未实测事项明确标注。使用方法见[诊断与优化指南](../DIAGNOSTICS.md)。

## 本地知识库与 zg 检索

「知识库」首页展示知识库卡片，打开后进入目录和文件详情。通过「导入本地」选择目录、文件或已有项目，也可通过「导入 Git」读取仓库及指定分支；导入完成自动构建索引，无需准备或下载模型。目录树可展开、搜索、预览和下载，改名、归档恢复及项目挂载放在更多菜单。进度、部分失败和索引错误按实际状态显示。

默认使用官方 Zvec 的原生 FTS/BM25，索引不含向量字段，不调用 embedding API，也不需要本地模型缓存。之前 zg 高层组合索引要求同时生成向量，已不作为默认路径。DSH 公开模型接口当前提供聊天生成，未提供通用 embedding；项目 AI 继续使用你在 DSH 中选择的模型，通过只读 search/read 理解召回资料。既有向量索引继续兼容，无需在知识库界面配置技术参数。

项目 AI 自动取得已挂载库的只读引用；输入 @ 可选择额外知识库作本次任务参考。准备任务时执行 BM25 召回，给出文件、行号与固定内容版本；模型只能检索、读取已准入资料，不能导入、索引、修改资料或扩大写入范围。源码及文档中的指令均按不可信参考处理。

当前支持代码、Markdown、HTML、UTF-8 文本及 JSON/YAML 等结构化内容。PDF、Office、图片、音视频保留原件，尚不提供解析/OCR。原件每文件64 MiB、每库2000文件；文本投影每文件最多1 MiB、索引语料总计64 MiB。私密路径、密钥、依赖目录、符号链接和穿越不导入。本地源始终只读；Git 只 fetch/readTree，不运行代码、hooks、子模块或 push。更新同路径会替换活动文档，旧原件及其 manifest 保留。

默认 FTS-only 索引通过官方 readOnly 打开，不需要临时写入。已有写权限内也可使用唯一隔离查询缓存，写根仅该目录，原资料与业务文件不包含在写根；旧向量索引需要独立副本以规避 Proxima O_RDWR。只读目标和原生权限不升级。索引/检索不联网、不启动独立 Python、数据库或 MCP 服务；Git 仅在显式导入时联网，复用现有代理/已信任 SSH profile。

公开只读 /api/designer/meta 仅提供版本、协议、静态能力和当前激活实例；业务 API 仍要求 owner。业务响应附版本和实例 header，可与工具状态对照，避免把旧 dispatcher 报错误当新知识库不支持。源码、产物和原生包装有可复现构建与完整性记录。

## 编辑和预览

真实 HTML、资源及受控交互/场景元数据是统一内容。编辑操作在 Host 上通过 AST 事务保存，源码、画布、预览和导出读取同一版本。`data-dsh-node` 是对象身份，不用显示名称或相似文字猜测目标。

编辑态支持选择、多个对象、框选、父级定位、图层定位、文字与图片属性、颜色字体、边框圆角阴影、尺寸间距、flex/grid、响应式属性及结构操作。移动遵守页面的流式布局；页面位置、画布相机与页面内部布局分别保存。共享定义与实例修改有独立范围，并在操作前列出影响对象。隐藏、锁定与明确解锁分别处理。

预览使用保存的内容，可以体验导航、返回、弹层、抽屉、tabs、切换、输入、校验、筛选和常见反馈。元素状态与 empty/loading/error/success 场景可配置。普通预览输入与导航是临时状态；明确保存为场景后才进入设计文件。密码和文件选择内容不被收集为示例场景。

切换预览前先处理未保存内容和校验。保存、结构校验、预览刷新以及交互是否实际验证分别显示，不能把文件写入成功当成全部交互已验证。无效操作和冲突保留候选内容，不强制覆盖其他修改。

总览与单页模式提供连续缩放、100%、适合窗口/选区、手型平移、设备与自定义尺寸、长页面滚动、网格、吸附和背景设置。页面数据按当前设计及可见范围加载。导出截图明确来自已保存页面或已保存场景；临时预览状态需要先明确固化。

## 文件、标签和恢复

查看器按类型处理 HTML、CSS/JS/TS、JSON/YAML、Markdown、图片/SVG、PDF、音视频及未知二进制。HTML 和 Markdown 的源码/渲染/分栏是同一资源的内部模式；Canvas 的编辑/预览也使用同一标签。未知二进制提供元数据和下载，不直接执行。

单击可打开临时查看标签，固定、双击或编辑后保留。资源以项目和稳定 ID 去重；同名文件显示父路径。标签支持排序、固定、关闭其他/右侧及已开列表。未保存内容不会被新的临时查看覆盖；切换保留光标、滚动、模式、相机与有效选区。

原始文件上传走流式入口，附件使用真实 DSH Session receipt，不通过巨型 base64 JSON 假装上传完成。PDF 和媒体支持只读范围读取，大文本分页读取。明确的文件、草稿、请求和资源尺寸上限会返回错误，失败不会显示为已保存。

外部修改通过实际文件版本与内容 hash 识别。协调操作区分采用外部版本、保留本地版本和合并，并保留双方内容。登记源码在用户明确解决冲突、拥有写入范围且通过 DSH 策略后，才以 CAS 写回实际工作树。普通设计版本与原始有效内容有独立备份，可撤销、重做或恢复。

机器视图状态、未发送对话草稿、任务上下文和临时能力地址与可交付内容分开管理，不进入普通 AI 自动文件上下文或交付包。

## AI 目标与引用

“当前查看内容”和“本轮修改目标”分别显示。查看、预览或加入引用默认只提供只读背景，不扩大写入权限。可以明确选择只读分析、选中对象、页面、设计、项目或精确源码文件；源码写入还需要该登记来源允许写入、明确路径及 DSH 原有策略共同成立。

提交时冻结目标、页面范围、有效体系版本、来源版本和引用摘要。后续切换标签或规范不会改变已提交任务。长需求与规则按版本保存业务快照并渐进读取；只读分析使用 DSH 自身的不可变附件存储，不借此修改项目。

文本、图片、附件、页面、对象、文件和来源引用可以一并发送。区域引用的真实截图由受信导出清单、原页面版本和 hash 核验后作为图像送入模型；历史截图保留为只读参考，过期几何不用于重新猜测对象。失效、缺失或篡改的引用会明确提示。

一个项目同时只接纳一个正在排队或执行的设计任务，避免后一个请求替换前一个请求的冻结权限。工具还核对原生 DSH 请求身份。模型只能调用业务工具，不能自行取得 Shell、任意文件写入、凭据、Git 写入或发布权限。项目任务之间相互隔离。

“打开完整会话”进入真实 DSH 对话与轨迹。工作台不另存一份聊天历史；历史展示、附件与状态均从原生 Session 读取。

## 技能

搜索和读取宿主可用技能，在更多操作中选择项目后启用。新增技能生成带合法 frontmatter 的 Markdown 文件下载；保存到 DSH 技能目录后刷新加载，尚未安装的文件不会插入可用列表。

## 设计体系

体系包含平台、tokens、规范文字、示例、骨架、扩展变量和版本化资源包。历史继续编辑会加载该版本的完整内容。资源可以明确进入文本草稿或保持逻辑路径替换文件，应用草稿后另存新版本；原版本字节不被修改。项目可以设置固定版本的默认体系；每个设计可继承、独立绑定或不绑定。修改绑定只影响之后的请求，不立即改写已有页面。

“按当前规范更新”是独立任务，先确认设计/页面/对象范围，再由真实 AI 生成并保存修改。仅提交请求时显示 pending，已有页面实际采用的版本与绑定版本分开记录。

体系资源保留逻辑路径和相对依赖，跨设计复制会复制所需资源并重写引用。外部导入包必须自包含，不允许包中的路径或 ID 借导入动作读取未选择的本地项目。共享来源仍遵守独立权限与影响范围。

## 网站、MasterGo 与 Figma

网站采集复用真实 Ego Chromium，可以操作菜单、表单、滚动、视口和页面状态。浏览器观察保留 DOM、样式、图片、字体和证据；观察到的行为、推断的行为、缺失资源与未验证路径分别记录。采集静态 DOM 不等于复制了原网站的后端或全部动态代码。

默认忠实还原来源，不自动套用项目视觉风格。明确选择规范改版时才使用指定的固定体系版本，并保留来源版本。原图/原页面与结果可以并排、覆盖或同步查看；局部刷新先产生差异提案，再按明确节点范围和版本应用，保留范围外的本地修改。

MasterGo 默认使用官方 Magic MCP 地址 `https://mastergo.com/mcp/xf/sse`；Figma 桌面 MCP 默认地址为 `http://127.0.0.1:3845/mcp`。连接测试读取真实服务 schema，凭据存 DSH credential service，不写入项目或 localStorage。账号权限、OAuth 或源文件访问不足时给出具体状态，也可导入导出的 HTML、JSON、图片或 ZIP 资料。图片资料保持参考性质，不冒充可编辑结构。

官方说明：[Figma MCP](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/)、[MasterGo Magic MCP](https://mastergo.com/help/ai-features/magic-mcp.html)。

## 源码、Git 和交付

登记源码可读取实际文件树，显式配置环境与写入路径，并通过受控 Shell 启动、查看日志和停止运行服务。可靠 source map 才用于源码定位；不可靠映射显示为参考，不猜测写入位置。关闭标签不默认停止正在使用的服务。

项目设置内提供「项目云同步」，画布更多菜单的「Git 云同步」可直接进入。每个项目独立绑定 HTTPS / SSH 仓库、分支与仓库内目录（默认 `designer-projects/<项目ID>`）；内置纯 JavaScript Git 与 SSH，不依赖系统安装 git、ssh 或 ssh-keygen。只更新所选子目录，保留分支内其他代码；不同仓库和分支的本地镜像隔离，防止旧仓库历史被带到新仓库。

提交、拉取、推送与「提交并同步」均为明确用户操作。可开启每分钟远端检测；它仅获取状态，不自动提交或发布。首次导入远端项目需确认，本地与远端同时变化或分支分叉时阻止覆盖及强推。拉取以新不可变文件版本和项目 CAS 发布，原文件与设计历史保留；本地原生会话、权限、只读引用和私有内容不进入云快照。

SSH 设置可生成 Ed25519 或导入私钥、公钥复制、检查主机指纹、明确确认信任及测试认证。密钥和 HTTPS 令牌由 DSH 原生凭据服务保存，不回显私钥、不修改系统 `~/.ssh`。外部已登记源码原有 `git.*` 工具继续保留，面向源码目录的旧工作流仍独立。

「导出 / 分享」可保存完整项目 ZIP，包含多设计稿原始页面模型、公开资源、需求规则及固定版本设计体系，另保留单页 / 设计交付包和 PNG/JPEG/WebP 图片。完整包包含自校验 `designer-project.json`，不会收集外部目录引用、私钥、对话或机器状态。快照上限 4000 文件、单文件 32 MiB、总计 128 MiB。

可直接复制所选页面 HTML 源码、已保存的 PNG 图片，或完整项目的便携文本编码；复制实际内容，不把下载链接当成文件。浏览器剪贴板不提供系统 ZIP 文件对象，因此完整 ZIP 使用下载保存，项目文本编码明确标示，剪贴板内容上限 16 MiB。图片由真实 Chromium 编码，PNG/JPEG/WebP 不改后缀冒充。背景、编辑标记与区域范围明确；不能确认的字体、资源或运行错误会单独报告。

预览分享固定一个保存版本，支持范围、明确更新和撤销。当前服务提供的本地链接会标明访问范围；它不是凭空创建的公网域名。没有配置真实外部发布服务时返回 `PUBLISHER_NOT_CONFIGURED`，不会声称已经上线。交付包不包含对话、凭据、机器状态、绝对保存目录或临时预览能力地址。

模型入口保留 `designer_manage`、`designer_import`；业务能力通过 `designer_workbench` 的 help/options 发现。项目 Agent 只收到冻结范围的业务工具，权限由后端核验。
