# Versioned source workflows

Implementation: `new SourceWorkflows(owner)` with `execute(input,{signal,policy,user,agent,...})`. Lead routes **workbench.source.*** to this instance; the module also accepts source.* aliases internally. The old DesignerImports source.import remains separate. All new UI/tool calls use this one business layer, with outer frozen authorization enforced by the lead.

Persistence is **project.workbench.sourceImports**, never sourceProjects (that belongs to external source-code registration). IDs are x-uuid. Selection metadata is CAS-protected; larger immutable artifacts live under `sources/<x-id>/versions/<xv-id>/<xc-id>.json`, version.json, and proposals/xr-id.json. Archive bytes continue through existing asset-archive + composed Fs/shell; no Host node:fs, profile edits, bundle installation, or duplicate credential store.

## Exact UI interface

- `workbench.source.plan`: `{projectId,expectedRevision,kind:'website'|'figma'|'mastergo'|'files',name?,url?,pages?,viewports?,mode?:'faithful'|'system-adaptation',systemId?,systemVersion?}`. Page is `{id?:'xp-id',name,url?,sourceNodeId?,selected?,scope?:'page'|'regions',states?,regions?}`. Region-only capture requires at least one selected region and later read/compare limits source structure to those stable nodes plus their necessary ancestor/style context. State is `{id,name,actions:[{type,selector?,x?,y?,text?,key?,deltaX?,deltaY?,url?}],expect?:{nodeId?,selector?,url?,visible?,textIncludes?,value?}}`. Region is `{id,name,nodeIds?,rect?:{x,y,width,height}}`, document CSS pixels. Viewport is `{id,width,height}`. Returns `{project,projectRevision,source,connectionRequired,offlineEntry}`. No design is created.
- `select`: `{projectId,sourceId,expectedRevision,pages?,pageIds?,viewports?,states?:[{pageId,states}],regions?:[{pageId,...region}],target?:{pageId,nodeMap},reference?:{versionId,captureId,regionId?,nodeIds?}}`. Target nodeMap keys are local real node IDs, values are source stable IDs. Returns updated source/project/revision and optional readonly source reference carrying projectId/sourceVersion/pageId/captureId/regionId/nodeIds/screenshot. Invalid references are checked before mutation.
- `capture`: `{projectId,sourceId,expectedRevision,browserId?,useCurrentState?,allowPartial?}`. Existing authorized browserId can preserve the currently opened modal/tab state via useCurrentState:true. Selected pages × viewports × states are captured. Returns `{project,projectRevision,source,version,observations,browserId,nextTasks}`. Version captures are `{id,pageId,stateId,viewportId,path,sha256,status,preview}`. Observation is `{captureId,pageId,viewportId,stateId,status,evidence,interactions,warnings,failures,preview}`.
- `import`: `{projectId,sourceId,expectedRevision,fileId?,path?,entry?,nodeId?,allowPartial?}`. A file goes through owner.workbench `file.read` with encoding:base64, preserving its fileId/path/version. Without a file, reads selected official Figma/MasterGo node scopes through existing configured connection. A missing account/service returns `{status:'connection-required',error,offlineEntry}`. Otherwise returns the same source/version/observation shape. Images without structure are **reference-only**; provider/JSON structure is preserved, not flattened into an alleged complete raster conversion.
- `read`: `{projectId,sourceId,versionId?,captureId?,regionId?,format?:'context'|'html',offset?,limit?}`. Without captureId returns source/version/versions plus **outline:[{captureId,pageId,status,preview,nodes:[{id,parentId,name,tag,layout}],nodeTotal}]**, max 500 nodes per capture. Official provider IDs can become page.sourceNodeId in the next select/import. With captureId returns capture metadata, user-only HTML, and paged JSON text containing context/semantics/nodes/interactions. Offset/limit are characters, limit 1–30000.
- `compare`: `{projectId,sourceId,versionId?,beforeVersionId?,pageId?}`. Returns `{sourceId,beforeVersionId,versionId,diffs,result?,views,runtimeVerificationRequired:true}`. Diff fields include affectedNodeIds/affectedRegionIds, text/layout/attributes/structure/visibility changes, resourceChanges, identityWarnings. `views={modes:['side-by-side','overlay'],source:[{captureId,preview}],result,uiOwnsSynchronization:true,synchronized:['zoom','scroll']}`. UI synchronizes its own views. User-only source/result views carry their trusted assetBase; the Client discards source base/CSP/refresh before inserting that base into its opaque compare frame.
- `refreshPreview`: `{projectId,sourceId,expectedRevision,pageId,captureId?,versionId?,nodeIds?,nodeMap?}`. No versionId means observe a fresh source first. Returns `{projectRevision,proposalId,pageId,sourceVersion,affectedNodeIds,patches,diff,views,applied:false,interactionTasks}`. Proposal freezes each selected local subtree hash. It does not overwrite target HTML.
- `applyRefresh`: `{projectId,sourceId,proposalId,pageId,nodeIds:[explicit subset],expectedRevision,expectedArtboardRevision}`. Requires source/target membership, proposal hash, project/page CAS and selected subtree hashes; calls real document AST replace/remove operations with selection scope. A later edit in a selected region conflicts. Later edits outside selected roots survive when the caller supplies current project/page revisions. Returns normal artboard commit plus affected IDs and runtimeVerificationRequired.
- `generate` / `rebuild`: `{projectId,sourceId,versionId,expectedRevision,target:{projectId?,designId?,pageId?,nodeIds?,scope:'design'|'page'|'selection'},captureIds?,prompt?}`. Rebuild requires selection + pageId + real nodeIds. Returns `{projectRevision,sourceId,sourceVersion,ai,frozenTarget,state}`. owner.runAI receives frozenTarget/basis, frozen source version/capture IDs, sourceFidelity and bindingOverride. Faithful default passes `{mode:'none'}` rather than inheriting project styling. Explicit system-adaptation uses only the selected system. Acquisition/generation/visualReview/interactionVerification are separate states; the latter two remain pending until real host validation records otherwise.

Preview persistence is `{projectId,importId,path,mimeType}`. Every **user:true** output decorates previews with a temporary **url** capability suitable for img src; capabilities are never persisted in immutable source data or provided to model tools. Browser main previews add scope:'viewport'/observed dimensions; actual clipped region screenshots add scope:'region'/region rect. A full snapshot is never relabeled as a cropped region. Saved HTML asset references remain ordinary ../assets paths.

## Evidence and fidelity

Browser capture now supplies real DOM stable IDs (`data-dsh-node`), parent IDs, selectors, text/attributes, measured layout and visibility, and anchor navigation. Authored IDs/test IDs are preferred; structural fallback identities are explicitly warned in diffs. Capture clipping uses CDP screenshot clip in logical CSS pixels, while DOM/bytes remain genuine browser capture.

State evidence separates observing a source control, dispatching an action, observing an expected/changed state, and running the generated behavior. Source controls default to missing generated behavior. Only source actions with a verified explicit expected state are marked observed in the source environment. A page change following an action without an expectation is inferred causality, and an unchanged/failed expectation remains missing. Generated behavior is never promoted to observed merely by observing the source. Sampled viewport sizes are observed; behavior between sizes is inferred. Official component/layout/prototype semantics and version provenance remain stored alongside full source context. A prototype record alone is not runtime verification.

## Limits and verification boundary

Selections are bounded to 12 pages, 5 viewports, 12 states/page, 20 actions/state and 36 page/state/viewport combinations. Each source operation has a three-minute admission budget checked between browser/provider/archive calls; the underlying browser and network operations retain their own hard deadlines. JSON artifact files are bounded to the store's 4 MB read contract. ZIP is memory-only, single-disk, methods store/deflate, max 500 entries / 32 MiB expanded; encrypted/unsafe paths/symlinks/CRC mismatch/duplicate names are refused. Other compression methods and ZIP64 need a normal extracted export through the workspace API rather than an unsafe fallback.

Official live provider authorization and its exact private-file semantics remain an external account condition. The module keeps full context plus bounded semantic indexes, layout/components/prototype metadata and source/file versions. A bounded index or source screenshot does not establish finished conversion. Standalone HTML export IDs are normalized before asset localization so reimporting identical files preserves node identity and does not report every new asset archive folder as a source change. Source resources and imported source files remain separate from generated design pages.

Regional source patches inline captured computed declarations into the selected real nodes. Static before/after text or image pseudo content becomes real local span/img nodes with fresh dedicated identities and inline styles; no style/script/global-active nodes are injected into selection scope. Old capture pseudo marker attributes are removed from the replacement so their saved numeric selector does not render a second generated box. Counter/marker content, void/table/list containers and other unsupported pseudo expressions fail explicitly with SOURCE_REBUILD_REQUIRED before mutation. Existing authored global pseudo/font dependencies may still require a scoped AI rebuild and runtime review. Patches do not globally replace project stylesheets or unrelated document metadata. Refresh preparation runs the real document AST transaction in memory before persisting a proposal, so global-active, locked-node, container and external interaction scope violations surface before apply. Protected html/body document shells are excluded from default region proposals. New font-face/global stylesheet dependencies from unmeasured static exports may require explicit source.rebuild and runtime review; direct refresh always returns runtimeVerificationRequired rather than claiming visual/interaction completion. Source plan/generation defaults to faithful. The host AI adapter must honor sourceFidelity/bindingOverride and enforce its frozen target during model commits. Final visualReview and interactionVerification stay pending until the host's real checks complete.
